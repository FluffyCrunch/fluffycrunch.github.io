// 01 — ABOUT

Building Worlds, One System at a Time

I build games that run in the browser — no installs, no waiting, just a link and a playable world. My focus is HTML5 games in React and Phaser: gameplay systems, smooth animation, and interfaces that hold up on any screen.

The interesting part isn't the feature list, it's the real-time layer underneath it. I've built live multiplayer dashboards over WebSockets, audio synthesized live instead of loaded from a file, and rendering pipelines with no premade assets at all. I care as much about what holds a system together under load as how a level plays.

Outside of games I work full-stack — PHP, Laravel, REST APIs — so I don't flinch at the backend half of a game either. Right now I'm pushing further into 3D and WebGL, chasing the kind of depth a flat canvas can't give you.
